# ADR-005: Financial Personality as Core Feature
**Status:** Accepted | **Date:** 2026-06-25

## Decision
Financial Personality (Builder/Optimizer/Explorer/Achiever) is required MVP scope.

## Rationale
- Emotional differentiator — makes this "Wrapped" not just a report
- One additional LLM call, zero additional infrastructure
- Maximum judging impact for minimum implementation cost
